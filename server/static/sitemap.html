BabyTrack Sitemap

  • / — Main tracking page (client/carer view)
  • /admin — Admin dashboard (consultant: families, links, summaries)
  • /admin#login — Admin login form
  • /admin#dashboard — Admin family list with daily stats
  • /admin#family/{id} — Family detail: CRUD, access links, date-picked summary
  • /t/{token} — Magic link redirect (sets token cookie, redirects to /)
  • /ws — WebSocket endpoint (sync protocol)
  • /health — Health check ({"ok":true,"version":"0.2.0"})
  • /log — Client error log receiver (POST)
  • /manifest.json — PWA web app manifest
  • /sw.js — Service worker (offline cache)
  • /icon-192.png, /icon-512.png — PWA app icons

Admin API (cookie-protected)

  • POST /admin/login, POST /admin/logout
  • GET /admin/session — Validate current session
  • GET /admin/families, POST /admin/families
  • GET /admin/families/{id}, PATCH /admin/families/{id}
  • GET /admin/families/{id}/summary — Daily summary with sleep stats
  • GET /admin/families/{id}/links, POST /admin/families/{id}/links
  • DELETE /admin/families/{id}/links/{token}
